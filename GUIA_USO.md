# Guía de Uso — chatPPSS4 📖

## Primeros pasos
1. Selecciona la carpeta donde tienes tus juegos de PS4
2. Elige el motor de emulación en Ajustes
   - FEX → mejor compatibilidad
   - Box64 → más velocidad
3. Toca un juego para iniciarlo

## Controles táctiles
- Tocar el panel táctil → funciona como el del mando real
- Deslizar sobre el panel → movimientos del cursor
- Stick izquierdo → movimiento del personaje
- Botones de acción → △ ○ □ ×
- L1/L2 y R1/R2 → gatillos superiores
- Botón PS → menú del sistema

## Formatos soportados
- .pkg
- .ps4
- Carpeta extraída
